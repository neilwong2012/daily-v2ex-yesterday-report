- **排障方法**：按链路分层定位：无线扫描 → 关联 → WPA 握手 → DHCP → 互联网 → 云服务。根据日志判断失败层，避免盲目尝试他人方法。
- **注意事项**：不同设备故障原因可能不同，例如有的设备已获取 IP 但注册失败，需区分。修改配置后建议重启路由器，避免驱动残留状态。
