### 关键要点
- 佩戴体验：类似印章贴片，内置软针，痛感轻微，可连续使用约半个月，洗澡时需注意防水。

- 购买渠道：京东有“七天全返”活动，连续监测7天可返全款，但存在失败风险。

### 评论补充

### 核心内容

作者开发了开源 CLI 工具 `teamai-cli`，解决团队使用多种 AI 编程工具（Claude Code、Cursor、Codex）时配置不一致、知识难以沉淀的问题。核心思路是将团队的 skills、rules、docs、环境变量、hooks、MCP 配置统一放在 Git 仓库中，通过 `teamai push` 创建 MR 评审，合并后通过 SessionStart hook 自动 `teamai pull` 同步到各工具目录。

### 关键要点

- **多工具一份维护**：skills 自动写入 `~/.claude/skills/`、`~/.cursor/skills/`、`~/.codex/skills/` 等，避免重复拷贝。
- **环境变量作为一等公民**：测试环境地址、凭证等配置随 pull 注入 shell，解决新人连不上测试环境的问题。
- **不绕过评审**：push 默认开 MR，必须人工评审，自动同步但不自动写入。
- **经验沉淀**：检测到摩擦信号（打断/纠正 AI、拒绝工具调用等）时，提示用户总结 learning 推给团队。
- **安装使用**：`npm install -g teamai-cli`，单人可用，`teamai init --repo  ` 初始化。

### 评论补充

评论建议不应只写 `~/`，还应支持仓库级目录（如 `.codex/`、`.cursor/`、`.claude/`、`.agents/`），作者回复已支持仓库级配置。
